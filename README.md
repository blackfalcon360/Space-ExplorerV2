# Space Explorer 🪐

Kid-friendly astronomy app.
- **Sky Compass:** a compass dial that turns with the phone. The Sun, Moon (with the real phase) and the planets sit where they really are in your sky, drawn as crisp icons (no glow, so neighbours never blur together). A time bar lets you slide the sky up to 12 hours either way, and jump whole days. Tap one to learn about it.
- **Planets:** the Sun, 8 planets and the Moon as tap-to-open cards with simple facts and "Did you know?" fun facts.
- Works offline (no INTERNET permission): positions are calculated on the phone from time + GPS location.

Brought to you By: Black Falcon 🦅

## Build
Push to GitHub -> Actions -> "Build APK" -> download `SpaceExplorer-APK`.
Local: `gradle assembleDebug` (JDK 17, Gradle 8.7+).

Package name: `SpaceExplorer.blackfalcon.jan` — portrait only.
